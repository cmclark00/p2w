Helper setup

Receive signed helper updates directly from Play2Win, without waiting for a Web Store review.

One-time setup required

A manager must enroll each shop computer in Chrome Enterprise Core and assign the helper. Signing in with the same Gmail account is not enrollment. The download below remains manual until this setup is complete.

For staff

  1. Ask a manager to enroll this computer using the steps below.
  2. Once the managed Play2Win helper appears at chrome://extensions, disable any older manual or Store copy. Keep only one enabled.
  3. Refresh the pricing tool and check Connected plus its version. Chrome checks for future managed releases automatically while running; updates are not instantaneous.

A Connected message confirms the helper responds. It does not by itself prove the computer is enrolled or that automatic updates are configured.

Manager: enroll computers and assign the helper
  1. Use the shop's Google Admin account with Chrome Enterprise Core. If needed, set up Core with a shop-controlled work email and complete Google's verification and terms.
  2. Create a dedicated shop-computer organizational unit. In Chrome browser → Managed browsers → Enroll (or Devices → Chrome), obtain its Windows enrollment file. Follow Google's enrollment instructions on one test computer first. Enrollment applies browser policies across that computer's Chrome profiles. Keep the enrollment file private.
  3. Restart Chrome when staff can safely close it. Confirm the computer appears in Managed browsers and chrome://management shows it is managed.
  4. For that organizational unit, open Apps & extensions → Users & browsers. Choose Add Chrome app or extension by ID → From a custom URL, enter the values below, and set Force install. Save. Google's policy instructions.
  5. At chrome://policy on the test computer, click Reload policies and check the helper's policy has no errors. At chrome://extensions, confirm the helper ID below is installed. Disable other Play2Win copies, refresh pricing, and run the connection checks.
  6. After the test succeeds, enroll the remaining shop computers into the same organizational unit. Do not enroll personal computers or change unrelated browser policies.

These two values are public. Never paste an enrollment token, password, or signing key into the pricing tool.

Updates and troubleshooting

Managed copy: Chrome checks Play2Win's update feed automatically. If a version stays old, a manager should check enrollment, the assigned policy and any version pin. Refresh the pricing page after the extension updates.

Manual copy: Download the latest helper ZIP. Extract to a permanent folder. At chrome://extensions, disable other Play2Win copies, enable Developer mode, then choose Load unpacked and select the folder containing manifest.json. Keep the folder. For later updates, replace its files and click Reload on the extension card.

Not connected: Check that the helper is enabled in the same Chrome profile, then refresh the pricing page. Manual installs do not gain automatic updates just by downloading this ZIP.

Pricing rules and premiums are unchanged. The helper checks market pages; it never buys, bids, submits offers, or changes carts. Extension privacy.
