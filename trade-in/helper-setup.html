Install or update the helper

Download the latest helper ZIP

First install

Extract the ZIP to a permanent folder. In Chrome, open chrome://extensions, enable Developer mode, then choose Load unpacked. Select the folder containing manifest.json and keep that folder.

Update an existing copy

Extract the latest ZIP over the same folder, then click Reload on the helper's card at chrome://extensions.

Keep only one Play2Win helper enabled. Refresh the pricing tool afterward and check the connected version.

Updates are manual. Pricing rules and premiums are unchanged.
