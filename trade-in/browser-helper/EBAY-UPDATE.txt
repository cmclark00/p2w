Play2Win Market Helper 1.1.6

Update each staff computer/profile manually:
1. Download the helper ZIP from Floor Pricing and extract it over the helper's
   permanent folder (the folder containing manifest.json).
2. Open chrome://extensions and click Reload on Play2Win Market Helper.
   Allow eBay search-page access if Chrome asks. Keep only one helper enabled.
3. Refresh the pricing tool. The header should say Connected - v1.1.6.
For first installation, enable Developer mode and choose Load unpacked instead.
Manual guide: https://play2wingames.com/trade-in/helper-setup.html
Connection checks: https://play2wingames.com/trade-in/helper.html
Privacy: https://play2wingames.com/trade-in/helper-privacy.html

New: direct eBay sold search can discover sales PriceCharting missed. It reads
one page of up to 120 results, highest price plus shipping first, in a temporary
background tab. Edition lookups also search the standard game separately.
All conditions share that search; results are matched to the selected condition.
A positive Sold date and a visible non-struck USD item price are required.
Accepted offers are excluded; or Best Offer alone does not mean accepted.
Shipping is displayed separately and does not change the existing price rules.
The same item ID counts once across both sources. Positive dated sold results
can resolve a generic Ended archive; price/identity conflicts still need review.
Unknown packaging, variants, bundles and outliers keep their normal safeguards.
Direct sold cards do not open redundant individual item tabs. Existing targeted
checks still verify other price-driving sales, in pairs after the first check
with GameStop, until verified or eligible evidence is exhausted.

The first result page is not a complete history of eBay. More pages, unreadable
cards, blocked searches and missing sign-in are flagged for review. Use Open
search to inspect more results. Sign in to eBay in the same Chrome profile if
needed; the helper never fills credentials or solves challenges. Search waits
are bounded; typed reviewed prices remain available. Search results are cached
in memory for 5 minutes. Bulk audits/rechecks never open helper tabs.

It reads only Play2Win trade-in, matching GameStop product, original eBay item
and eBay search pages. It never buys, bids, submits offers, changes carts or
messages sellers. Temporary tabs close automatically. Specific premiums,
rare-figure minimums and existing rounding remain in the pricing tool.
The website cannot reload an installed Chrome extension for you. This manual
installation does not auto-update and cannot run in the Codex in-app browser.
